* Reshaping

Learning how to work with and analyze real-world datasets.

Focus areas:

* DataFrames and Series
* Data Loading
* Data Cleaning
* Filtering
* Sorting
* Grouping

* Merging

### 08 — AI Agents & Agentic AI 🤖
